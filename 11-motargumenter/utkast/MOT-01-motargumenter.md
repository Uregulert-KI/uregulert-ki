# MOT-01 Motargumenter og avveininger

## Stikkord og materiale fra disposisjonen

Målet er å møte de sterkeste motargumentene, ikke stråmenn. Kapitlet øker troverdigheten til resten av rapporten.

| Motargument | Hvem fremmer det | Rapportens svar (utkast) |
| --- | --- | --- |
| Regulering hemmer innovasjon og konkurransekraft | Næringsliv, Draghi-rapporten | Regulering kan gi tillit og forutsigbarhet; målrettede krav fremfor generelle forbud |
| Norge er for lite til å påvirke | Pragmatikere | Norge kan regulere egen offentlig sektor, skole og innkjøp; påvirkning via EØS og Europarådet |
| KI gir store gevinster i helse, forskning og offentlig sektor | Forskere, forvaltning | Enig – nettopp derfor må risikoen håndteres slik at gevinstene kan hentes trygt |
| Mye av evidensen er tynn | Forskere | Enig der det stemmer; føre-var-prinsippet ved alvorlig og irreversibel skade |
| Tidligere teknologipanikk slo ikke til | Teknologihistorikere | Vis hva som skiller KI: tempo, skala, overtalelsesevne, autonomi |
| KI kan også motvirke farene (f.eks. oppdage svindel og desinformasjon) | Industri, forskere | Riktig; regulering bør fremme slik bruk |
| Brukere er voksne og bør velge selv | Liberale stemmer | Gjelder ikke barn og sårbare; informert valg forutsetter åpenhet |
