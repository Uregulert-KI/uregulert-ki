# INN-02 Definisjoner

## Stikkord og materiale

*Utvidet 2026-11-01 etter gjennomgang.*

- **Kjerne:** de få definisjonene som avgjør hva rapporten handler om. Øvrige termer står i [ordlista](../../metode/ordliste.md).
- **Avgrensning:** verdiene er definert i [[INN-03]], risikotypene i [[RAM-01]] og tidshorisonten i [[RAM-02]]. Hva som faller utenfor rapporten, står i [[INN-05]].

### A KI

- **Juridisk:** rapporten bruker definisjonen av KI-system i KI-forordningen (art. 3) [K0001].
- **I praksis:** rapporten handler mest om *generativ KI*. Når ikke annet er sagt, menes **store språkmodeller og systemene som bygger på dem**: chatboter, assistenter og KI-agenter.
- **Andre typer KI nevnes eksplisitt** der de omtales: prediktive modeller og klassifisering ([[RET-06]], [[RET-07]], [[OKO-03]], [[OKO-10]]), ansiktsgjenkjenning ([[RET-04]]), bilde- og stemmegenerering ([[DEM-03]], [[LIV-16]]) og autonome våpen ([[SIK-06]]).

### B Uregulert

- **Definisjon:** KI-bruk og -utvikling som ikke fanges opp av dagens regelverk, eller som ikke håndheves effektivt.
- **Regler finnes:** KI-forordningen [K0001] og personvernforordningen [K0002] gjelder. Poenget er hullene: det som faller utenfor, det som kommer for sent, og det som bare binder de lovlydige ([[REG-02]], [[RAM-02]]).

### C Fare og risiko

- **Fare:** noe som kan skade en verdi i [[INN-03]].
- **Risiko:** faren vurdert etter sannsynlighet og konsekvens ([[RAM-01]], [[VED-01]]).
- **Førsteordens effekter:** direkte skade fra ett system.
- **Andre- og tredjeordens effekter:** skade som oppstår når mange systemer virker sammen over tid og endrer atferd, institusjoner og maktforhold ([[TVG-04]]).

### D Tidshorisont

- **Nå, nær og fjern** er definert i [[RAM-02]].
